## Source and release identity

Builds from this repository use its standalone repository identity and root paths.
They do not need a live `onesa-ug` checkout, another product's runtime, or a shared
release. Existing schema-2 consolidated-source readers remain compatibility code
for their original, explicitly pinned records; their original repository IDs, source
paths, signatures and acceptance must not be relabelled as standalone evidence.
An old consolidated authorization does not authorize a new standalone source.

The owner-controlled standalone release process must qualify the actual current
source, CI, artifacts, staged runtime and rollback before deployment. Original
accepted records, unresolved operations, credentials, data and recovery remain
independent. Updating source is not proof that a live application has been updated.
