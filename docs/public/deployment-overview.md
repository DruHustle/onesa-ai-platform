# Service operation overview

## Independent products and releases

Onesa products and documentation are released independently. A documentation update does not change an application or approve a production release. Validation distinguishes a build, a controlled staging release and a verified production deployment.

[Public developer documentation](https://docs.onesa.eu) contains explicitly approved guides, diagrams and manuals. Engineering implementation details, infrastructure configuration and privileged procedures belong to the protected engineering experience.

## Development and production

Development uses isolated fixtures and clearly identified simulation or mock output. Staging validates candidate behavior with separate data and credentials. Temporary previews are not canonical production URLs and must not be treated as public publishing destinations.

Public product pages describe their current development status. A healthy webpage does not prove that every model dependency or physical integration is ready. Independent non-AI functions should remain usable when inference is unavailable.

## Configuration and private data

Product identity, public or protected access, deployment context and simulation or live operation are separate. Private application data and credentials are never browser configuration. Links between Onesa products do not transfer sessions or permissions.

The public documentation host does not execute privileged API requests or provide access to internal manuals, private indexes or application data. Full operational configuration is restricted to authorized engineering users.

## Monitoring and recovery

Releases require appropriate application, dependency and security checks, relevant staged acceptance and owner-controlled production deployment. Hosted verification establishes which candidate is serving users. Recovery procedures preserve data and use verified artifacts; a backup setting alone does not prove restoration works.

Public descriptions omit private service identifiers, infrastructure addresses, repository layouts and incident records. Contact Onesa through the [Company enquiry form](https://onesa.eu/en/contact).
