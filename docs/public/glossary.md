# Technical glossary

| Term | Meaning |
| --- | --- |
| ModelClient | Shared inference contract used by applications |
| RAG | Retrieve attributed knowledge context before generation |
| pgvector | PostgreSQL vector storage and similarity operations |
| Lexical baseline | Deterministic hashed term vectors; not semantic model embeddings |
| SSE | Server-Sent Events carrying incremental chat output |
| CSRF | Session-bound protection for browser mutation requests |
| LoRA / QLoRA | Separately qualified parameter-efficient fine-tuning approaches |
| Registry | Immutable candidate metadata/artifacts, not evidence of deployed weights |
| Verification | Recorded execution evidence, distinct from proposed configuration |
