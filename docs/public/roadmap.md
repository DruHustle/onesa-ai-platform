# Roadmap and known limitations

## Completed
Authenticated persisted Chat; owned Knowledge ingestion/retrieval; bounded local agents; saved typed Travel; real local Ollama inference and small baseline evaluation; documentation source/build foundations.

## Current engineering milestone
M3.2 is locally qualified on fixed synthetic English/German retrieval using the existing Qwen3 embedding service; the lexical baseline remains available and clearly labelled. This does not establish hosted serving or broad multilingual/customer quality. The next ordered feature milestone is authorized live travel-provider acceptance (M5); current release work prioritizes security, hosted application and operational qualification (M7).

## Unverified or proposed
NVIDIA target-host serving; hosted semantic embedding/reindex and approved-corpus quality; live travel-provider integrations; approved-data fine-tuning; distributed GPU routing; actual production security/load/TLS/retention, recovery/email delivery, accessibility and operational/legal review. Local invitation/recovery and bounded upload controls are implemented behind explicit configuration; they do not open or approve a public pilot.

UI language catalogs cover English/German navigation and sign-in; reviewed multilingual documentation is not available. Proposed capabilities and checklists are not successful infrastructure validation.
