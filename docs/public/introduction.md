# Onesa AI developer documentation

Onesa AI is a European-based, globally applicable general-purpose platform. Chat, Knowledge, Agents and Travel share authenticated APIs and configurable open-weight inference. FastAPI/Python, Next.js/TypeScript and PostgreSQL/pgvector are the implemented foundation. Local Ollama inference has been verified; NVIDIA hosting, semantic embeddings, live travel providers and fine-tuning qualification remain pending.

Start with [quickstart](quickstart.md), [applications](applications.md), [API integration](integration.md) and [roadmap](roadmap.md).
