# Onesa AI developer documentation

Onesa AI Platform is a European-based, internationally applicable platform for
conversations, private knowledge and guided application workflows. Chat, Knowledge,
Agents and Travel share authenticated APIs and configurable inference providers.

Start with a question in Chat, or add your own source in Knowledge before asking
source-backed questions. Agents use the registered, permission-controlled tools;
Travel produces editable itinerary suggestions rather than bookings. Sign in with
an existing platform account. Registration or a private invitation depends on the
deployment's access policy; an ordinary account grants no engineering or Robot access.

The local quickstart uses explicitly labelled mock inference and lexical retrieval.
It does not qualify a hosted model, semantic retrieval or customer-data processing.
GPU hosting, training, live travel services and physical Robot integration require
their own implementation and qualification.
